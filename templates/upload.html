입력양식 등록 (원본 당직명령 엑셀)

월별 원본 당직명령(.xlsx)을 그대로 등록할 수 있습니다. 예: 2026년_7월_본사_당직명령.xlsx

  • 순서 — 직원·부서·평일/휴일별 순서와 제외 상태, 스킵·복귀월을 반영합니다.
  • 당직명령 — 해당 월의 실제 당직 이력과 다음 달 시작 순번을 반영합니다.

‘기준 월말 DB 구성’ 선택 시 DB를 자동 백업한 뒤, 선택한 월과 이후의 당직 생성분을 원본 기준으로 대체합니다. 이전 월 이력과 수동 예외·직원 변동 이력·시스템 설정은 보존합니다. 원본 명부에 없는 기존 직원은 이력을 유지하며 정규 배정에서 제외합니다.

예: 7월 원본으로 기준 DB 구성 → 8월 원본을 ‘직원 명부만 갱신’으로 등록 → 8월 배정 생성. 원본 등록만으로 생성 규칙의 차이가 해결되는 것은 아니므로 생성 후 원본과 비교해 주세요.

기존 입력양식(직원명부(마스터)·초기당직이력(2월))도 계속 사용할 수 있습니다. 구형 .xls 파일은 Excel에서 .xlsx로 저장한 뒤 등록하세요. 원본 내 성명·사번 오류나 평일/휴일 차이는 등록 결과에 표시됩니다. 스킵 내역 표가 없는 파일(예: 10월)은 직원 명부만 갱신으로 등록해 기존 복귀 대기를 유지하세요.
